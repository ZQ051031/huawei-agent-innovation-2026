# 华为云码道使用证明 — 等参赛者提供真实证据

本目录只有清单，并不是使用证明。没有运行码道 IDE、没有登录/注册、没有伪造使用日志。官网要求在开发过程中将华为云码道用作核心 AI 编程工具；仅截图打开 IDE 或复制一段已有代码并不足以证明这一点。

1. 在码道 IDE 打开本项目。保存确有使用的 IDE 插件日志、操作记录或可导出的会话；让工作区名称、时间、相关文件和动作可辨认。
2. 用码道完成实际开发：例如改进中英发票解析、增加重复检测边界用例、调试 PDF 提取或者精炼报表证据逻辑。保留任务描述、Prompt、完整关键对话、建议修改及接受/拒绝理由。
3. 各保留至少一组有代表性的**生成、重构、排错**记录：截取对话和 diff，关联真实提交，展示同一问题修复前后测试。保留环境搭建/文档生成的真实记录（如果用到了）。
4. 记录文件、提交号、可复现命令、实际结果、发现的问题，以及可证实的单人开发收益。没有测量就不填写效率百分比。不要拍进 API 密钥、客户凭证、账户信息、私人联系方式或正式账目。
5. 将实际证明文件放进提交包的 `codearts_proof/`，并把核实后的应用说明写入 PPT/PDF 与 `readme/`。不要将私人截图推到公共仓库。
